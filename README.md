# 小・中学生向けWebサービスのUI/UXガイドライン

小学校低学年から中学生までが、安全に、迷わず、自分の意思で使えるWebサービスを設計するための日本語ガイドラインです。

学習、創作、情報閲覧、学校内での利用などに共通する設計の土台をまとめています。学年だけで能力を決めつけず、読解力、操作経験、障害、使用言語、端末、利用環境の違いを検証します。

## ドキュメント

- **[UI/UXガイドライン](UIUX-GUIDELINES.md)**：設計原則、学齢別の配慮、画面・文章・操作、アクセシビリティ、プライバシー、安全、実装例、調査方法、一次資料。
- **[レビュー・公開前チェックリスト](REVIEW-CHECKLIST.md)**：企画、デザイン、実装、運用の担当者が判定と証跡を記入できるテンプレート。

## 最初に使うとき

1. 対象学齢、提供地域、利用目的、共有端末の有無を決める。
2. ガイドラインの「使い方」と「最優先の原則」をチームで確認する。
3. 主要な利用フローにルールIDを割り当て、チェックリストへ証跡を残す。
4. 子ども本人と支援者の協力で試し、結果に応じて設計を変える。
